# File I/O e gestione dati

## Obiettivo
Imparare come leggere e scrivere file in Fortran in modo robusto, inclusi dati scientifici, file di testo e formati strutturati.

## Argomenti da coprire
- open, close, read, write
- formatted e unformatted I/O
- file di testo e dati tabulari
- error handling per I/O
- performance in lettura/scrittura

## Contenuti da aggiungere nel tempo
- esempi di parsing di dati scientifici
- gestione errori file not found, permission denied, malformed data
- uso di formati e output controllato

## Esercizi consigliati
- leggere un file di dati e calcolare statistiche semplici
- scrivere risultati in file CSV o testuali
- gestire input da file e output sintetico
