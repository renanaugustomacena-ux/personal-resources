# Capstone e progetto finale

## Obiettivo
Consolidare tutto il percorso in un progetto reale, complesso e verificabile, in linea con l’uso professionale di Fortran.

## Proposte di progetto
1. Simulatore numerico semplice di un sistema fisico
2. Modello di crescita/epidemia o sistema dinamico
3. Solver numerico per equazioni differenziali o algebra lineare
4. Pipeline di elaborazione dati scientifici con input/output strutturati
5. Libreria modulare per calcoli scientifici con test e build automatizzati

## Requisiti del progetto
- codice organizzato in moduli
- uso di array, procedure e gestione file
- documentazione minima del progetto
- test o verifiche di correttezza
- benchmark o analisi di performance
- eventuale integrazione con C, Python o librerie esterne

## Deliverables attesi
- repository con sorgenti e README
- esempi di esecuzione
- documentazione tecnica
- risultati e osservazioni finali
