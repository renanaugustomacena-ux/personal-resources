# Guida ai tutorial Fortran

Questa sezione raccoglierà una serie di tutorial pratici progettati per accompagnare la teoria con esercizi eseguibili e verificabili.

## Obiettivi dei tutorial
- costruire un workflow di apprendimento pratico
- mostrare esempi compilabili e testabili
- introdurre progressivamente concetti avanzati
- favorire l’adozione di best practices fin da subito

## Piano dei tutorial
1. Hello world e primo programma
2. Variabili, operatori e controllo di flusso
3. Array e stringhe
4. Procedure e subroutines
5. Moduli e organizzazione del codice
6. Derived types e type-bound procedures
7. File I/O e parsing di dati
8. Allocatable arrays e puntatori
9. Interfaccia con C e librerie esterne
10. OpenMP e parallelismo di base
11. Uso di fpm e build tools
12. Debugging, testing e profiling

## Metodologia consigliata
- ogni tutorial deve includere: obiettivo, codice, spiegazione, output atteso, variazioni possibili
- ogni esempio deve essere compilabile in modo indipendente
- gli esercizi devono diventare più complessi gradualmente
- ogni tutorial dovrebbe terminare con un mini-esercizio di consolidamento
