# Build systems, packaging e distribuzione

## Obiettivo
Imparare a gestire progetti Fortran in modo professionale tramite strumenti moderni di build e packaging.

## Argomenti da coprire
- make
- CMake
- fpm (Fortran Package Manager)
- organizzazione di progetti multi-file
- distribuzione di librerie e strumenti

## Contenuti da aggiungere nel tempo
- esempi di project layout professionale
- workflow per progetti scientifici e condivisi
- integrazione con CI/CD e repository

## Esercizi consigliati
- creare un progetto con più moduli e un file principale
- usare fpm per compilare ed eseguire il progetto
- preparare una struttura pronta per condivisione e distribuzione
