# Glossario — Data Encyclopedia

## Database
- **RDBMS**: Relational Database Management System
- **MVCC**: Multi-Version Concurrency Control
- **WAL**: Write-Ahead Log
- **ACID**: Atomicity, Consistency, Isolation, Durability

## Data Engineering
- **ETL**: Extract, Transform, Load
- **ELT**: Extract, Load, Transform
- **CDC**: Change Data Capture
- **Data Lake**: Repository per dati raw
- **Data Warehouse**: Repository per dati strutturati

## Processing
- **Spark**: Distributed computing framework
- **Kafka**: Event streaming platform
- **Airflow**: Pipeline orchestration
- **dbt**: Data build tool

## Security
- **GDPR**: General Data Protection Regulation
- **PII**: Personally Identifiable Information
- **DPA**: Data Processing Agreement
- **DPIA**: Data Protection Impact Assessment

## Cloud
- **IAM**: Identity and Access Management
- **S3**: Simple Storage Service
- **BigQuery**: Serverless data warehouse (GCP)
- **Redshift**: Data warehouse (AWS)
