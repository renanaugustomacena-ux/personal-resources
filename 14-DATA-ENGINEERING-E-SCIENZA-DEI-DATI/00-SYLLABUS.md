# Syllabus — Data Engineering e Scienza dei Dati

> Lingua: italiano · Aggiornamento: 2026-05-04
> Versioni: PostgreSQL 16+, MySQL 8.0+, MongoDB 7+, Kafka 3.6+, Spark 3.5+, Python 3.12+

## Identita

**"Data Encyclopedia — da basi relazionali a threat modeling"** — Enciclopedia completa per data professionals.

**Target:** Expert (tutti senior) — deep-dive, internals, production patterns, certificazioni.

## Pilastri

### I — Database Systems (01-14)
- 01-04: RDBMS (PostgreSQL, MySQL, SQLite)
- 05-11: NoSQL (MongoDB, Redis, Cassandra, ES, TimescaleDB, ClickHouse, Neo4j)
- 12-14: Migrations, Replication, Security

### II — Data Engineering (15-25)
- 15-16: Data Warehouse, ETL/ELT
- 17-21: Orchestration (Airflow), Transform (dbt), Processing (Spark, Kafka)
- 22-25: Pipelines, Quality, Governance, Observability

### III — Data Analysis (26-32)
- 26-27: EDA, Pandas/NumPy
- 28-30: Visualization, BI, Jupyter
- 31-32: SQL Analytics, ML Intro

### IV — Cloud Data Platforms (33-37)
- 33-34: Big Data Architecture, Data Lake
- 35-37: AWS, GCP, Azure Data Services

### V — Data Protection & Security (38-48)
- 38-42: GDPR, Encryption, Classification, Audit, Anonymization
- 43-48: Threat Modeling, Breaching, PenTesting, IR, Monitoring, Compliance

## Certificazioni Mappate
- AWS: DA-C01, DE, ML, Security Specialty
- GCP: Data Engineer, Cloud Security
- Azure: Data Engineer, DP-100, SC-900
- CDMP, CISSP, CISM, OSCP, GCIH

## Capstone

Progetto completo: CDC Postgres → Kafka → Spark Streaming → ClickHouse → dbt → Looker + Security + GDPR compliance
