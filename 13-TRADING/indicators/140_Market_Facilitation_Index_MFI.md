# Indicator 140: Market Facilitation Index (BW MFI) — The Price of Movement

***"Volume is the fuel. Price range is the distance traveled. The Market Facilitation Index tells you if the engine is efficient or if it's struggling uphill." — Bill Williams***

---

## 1. Executive Summary

The **Market Facilitation Index (BW MFI)** is a unique indicator that combines **Price Action (Range)** and **Volume** to measure the efficiency of market movement. It answers a critical question: *How much price movement is being generated by each unit of volume?*

Unlike standard volume indicators (which just show activity), the BW MFI reveals the *quality* of that activity.

- If volume is high but price isn't moving, the market is fighting a battle (Squat).
- If volume is low but price is moving easily, the market is drifting (Fake).

The indicator is color-coded based on the interplay between the MFI value and Volume, creating four distinct states: **Green**, **Fade (Brown)**, **Fake (Blue)**, and **Squat (Pink)**.

In GOLIATH, the **Squat** signal is the most critical: it acts as a "Stop" sign, often appearing at the exact top or bottom of a trend.

---

## 2. Mathematical Foundations

The formula is elegantly simple:

$$ \text{BW MFI} = \frac{\text{High} - \text{Low}}{\text{Volume}} $$

Interpretation:

- **Numerator (High - Low)**: The distance the market traveled.
- **Denominator (Volume)**: The effort required to travel that distance.

A high MFI means price is moving easily (low resistance). A low MFI means price is stuck (high resistance or low volatility).

---

## 3. Signal Generation: The Four Colors

The signal is derived by comparing the current MFI and Volume to their previous values.

### 3.1 Green Bar (+MFI, +Volume)

- **Condition**: MFI > Prev MFI **AND** Volume > Prev Volume.
- **Meaning**: The market is moving, and volume is supporting the move. The "Green Light" for trend following.
- **Strategy**: Best time to enter or add to positions. The trend is valid and accelerating.

### 3.2 Fade / Brown Bar (-MFI, -Volume)

- **Condition**: MFI < Prev MFI **AND** Volume < Prev Volume.
- **Meaning**: The market is losing interest. The trend is fading. " The market is taking a nap."
- **Strategy**: Do not trade. High probability of chop.

### 3.3 Fake / Blue Bar (+MFI, -Volume)

- **Condition**: MFI > Prev MFI **AND** Volume < Prev Volume.
- **Meaning**: The market is moving, but volume is dropping. The move is unsupported by broad participation. It is "Fake."
- **Strategy**: Be skeptical. Often a trap set by market makers in thin liquidity.

### 3.4 Squat / Pink Bar (-MFI, +Volume)

- **Condition**: MFI < Prev MFI **AND** Volume > Prev Volume.
- **Meaning**: Volume is increasing (high effort), but price range is decreasing (low result). A massive battle is taking place between buyers and sellers, but neither side is winning yet.
- **Key Insight**: A Squat almost always occurs prior to a trend reversal or a massive breakout. It signifies a "Pause for Power."
- **Strategy**: Prepare for a reversal. If in a trend, tighten stops immediately. This is the **End of Trend** signal.

## 4. Implementation

### 4.1 Python Implementation

```python
import pandas as pd
import numpy as np

def compute_bw_mfi(df: pd.DataFrame) -> pd.DataFrame:
    """
    Compute Bill Williams' Market Facilitation Index (BW MFI).
    Must contain 'high', 'low', 'volume'.
    """
    df = df.copy()
    
    # Calculate MFI
    # Check for zero volume to avoid division by zero
    # Replace 0 volume with 1 (or NaN) to be safe
    vol_safe = df['volume'].replace(0, 1)
    
    # Scaling factor (often 1000 or similar to make numbers readable, but 
    # theoretically raw value is fine). Williams often used raw tick volume.
    df['bw_mfi'] = (df['high'] - df['low']) / vol_safe * 1000000 # Scale for readability
    
    # Determine Color State
    # Need comparing to previous bar
    mfi_up = df['bw_mfi'] > df['bw_mfi'].shift(1)
    vol_up = df['volume'] > df['volume'].shift(1)
    
    conditions = [
        (mfi_up & vol_up),      # Green
        (~mfi_up & ~vol_up),    # Fade (Brown)
        (mfi_up & ~vol_up),     # Fake (Blue)
        (~mfi_up & vol_up)      # Squat (Pink)
    ]
    
    choices = ['GREEN', 'FADE', 'FAKE', 'SQUAT']
    
    df['mfi_color'] = np.select(conditions, choices, default='UNKNOWN')
    
    return df
```

### 4.2 Rust Implementation

```rust
pub enum MfiState {
    Green,
    Fade,
    Fake,
    Squat,
    Unknown, // For first bar
}

pub struct BwMfi {
    prev_mfi: f64,
    prev_vol: f64,
}

impl BwMfi {
    pub fn new() -> Self {
        Self { prev_mfi: 0.0, prev_vol: 0.0 }
    }

    pub fn next(&mut self, high: f64, low: f64, volume: f64) -> (f64, MfiState) {
        let vol_safe = if volume == 0.0 { 1.0 } else { volume };
        let mfi = (high - low) / vol_safe * 1_000_000.0;

        let mfi_up = mfi > self.prev_mfi;
        let vol_up = volume > self.prev_vol;

        let state = if self.prev_vol == 0.0 {
             MfiState::Unknown
        } else if mfi_up && vol_up {
             MfiState::Green
        } else if !mfi_up && !vol_up {
             MfiState::Fade
        } else if mfi_up && !vol_up {
             MfiState::Fake
        } else {
             MfiState::Squat
        };

        self.prev_mfi = mfi;
        self.prev_vol = volume;

        (mfi, state)
    }
}
```

## 5. Strategy: The Squat Reversal

In GOLIATH, the Squat is a high-priority "Veto" signal.

1. **Trend Termination**: If the system is Long, and a Squat appears at a new High, the system triggers an immediate "Tighten Stop" routine (e.g., move stop to Low of the Squat bar).
2. **Breakout Validation**: If a Breakout occurs on a "Fake" (Blue) bar, it is ignored. Ideally, breakouts should occur on "Green" bars.
