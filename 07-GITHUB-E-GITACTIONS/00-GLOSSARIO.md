# Glossario — Git & GitHub Actions

> Aggregato moduli 01-28. 2026-04-27.

| Termine | Definizione |
|---|---|
| **ARC** | Actions Runner Controller K8s. |
| **Attestation** | Signed claim about artifact. |
| **Branch protection** | Rules require PR/review/checks. |
| **CODEOWNERS** | Per-path review automation. |
| **CodeQL** | Semantic SAST. |
| **Conventional Commits** | Standard commit message format. |
| **cosign** | sigstore signing. |
| **Dependabot** | Dep auto-updates. |
| **EMU** | Enterprise Managed Users. |
| **Environment (GHA)** | Deploy target con protection rules. |
| **Fork-PR** | PR da fork repository (security risk). |
| **GHA** | GitHub Actions. |
| **`gh` CLI** | Official GitHub command-line. |
| **GHCR** | GitHub Container Registry. |
| **HMAC** | Hash-based MAC (webhook verify). |
| **`id-token: write`** | Permission OIDC. |
| **Matrix build** | Multi-platform/version parallel. |
| **OIDC** | OpenID Connect. |
| **`permissions: {}`** | Minimum permission workflow. |
| **`pull_request` vs `pull_request_target`** | Untrusted vs trusted (security). |
| **Reusable workflow** | `workflow_call` invokable. |
| **Renovate** | Dep auto-update tool. |
| **SHA-pinning** | Pin action a SHA, not tag. |
| **SLSA** | Supply-chain Levels for Software Artifacts. |
| **Squash merge** | Combine commits into one. |
| **Trunk-based** | Single main branch + short-lived feature. |
| **Webhook** | HTTP POST on event. |
| **Workflow dispatch** | Manual trigger. |
| **`actions/cache@v4`** | Cache deps. |
| **`actions/checkout@v4`** | Checkout repo. |
