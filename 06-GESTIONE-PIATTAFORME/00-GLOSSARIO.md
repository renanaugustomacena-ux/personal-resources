# Glossario — Piattaforme Cloud-Native

> Aggregato moduli 01-22. Aggiornamento 2026-04-27.

| Termine | Definizione |
|---|---|
| **AKS** | Azure Kubernetes Service. |
| **ALB / NLB** | AWS Application/Network Load Balancer. |
| **ArgoCD** | GitOps tool K8s. |
| **Attestation** | Signed claim about artifact. |
| **AWS** | Amazon Web Services. |
| **BuildKit** | Docker advanced build engine. |
| **CIS Benchmark** | Hardening standard. |
| **Cloud-native** | Architettura per cloud, no lift-and-shift. |
| **CNCF** | Cloud Native Computing Foundation. |
| **cosign** | sigstore signing. |
| **CSI** | Container Storage Interface. |
| **DLP** | Data Loss Prevention. |
| **Distroless** | Minimal container image (no shell). |
| **DRA** | Dynamic Resource Allocation (K8s 1.30+). |
| **eBPF** | Extended Berkeley Packet Filter. |
| **EKS** | Amazon Elastic K8s Service. |
| **Erasure coding** | Distributed storage encoding. |
| **FinOps** | Cloud financial operations. |
| **Flux** | GitOps tool K8s. |
| **GCP** | Google Cloud Platform. |
| **GitOps** | Git as source of truth for ops. |
| **GKE** | Google K8s Engine. |
| **HPA** | Horizontal Pod Autoscaler. |
| **HSM** | Hardware Security Module. |
| **IaC** | Infrastructure as Code. |
| **IAM** | Identity and Access Management. |
| **Istio** | Service mesh. |
| **Kamaji** | Hosted control plane. |
| **Kata containers** | VM-isolated runtime. |
| **Kong** | API gateway. |
| **Kubernetes / K8s** | Container orchestrator. |
| **Kyverno** | Policy engine K8s. |
| **Linkerd** | Service mesh leggero. |
| **MinIO** | S3-compatible object storage. |
| **Multi-tenancy** | Isolation tra tenant. |
| **NetworkPolicy** | Firewall L3/L4 K8s. |
| **OIDC** | OpenID Connect. |
| **OPA** | Open Policy Agent. |
| **OpenTofu** | Open-source Terraform fork. |
| **OTel** | OpenTelemetry. |
| **Pod Security Standards** | K8s baseline-restricted-privileged. |
| **Prometheus** | Pull-based monitoring. |
| **Provenance** | Build origin metadata. |
| **PVC** | PersistentVolumeClaim. |
| **RBAC** | Role-Based Access Control. |
| **RED methodology** | Rate/Errors/Duration. |
| **Reserved Instance** | Pre-paid commitment cloud. |
| **ResourceQuota** | Limite resource per namespace. |
| **SBOM** | Software Bill of Materials. |
| **Service mesh** | mTLS + observability + traffic mgmt. |
| **SHA pinning** | Pin actions a SHA, not tag. |
| **Sidecar** | Container helper in pod. |
| **SLSA** | Supply-chain Levels for Software Artifacts. |
| **StorageClass** | Provisioner template per PV. |
| **syft** | SBOM generator. |
| **Tagging policy** | Cost allocation strategy. |
| **Terraform** | IaC tool. |
| **trivy** | Container vulnerability scanner. |
| **USE methodology** | Utilization/Saturation/Errors. |
| **Vault** | HashiCorp secret manager. |
| **vCluster** | Virtual cluster on shared K8s. |
| **WIF** | Workload Identity Federation. |
| **WAF** | Web Application Firewall. |
| **Zero-trust** | Never trust, always verify. |
