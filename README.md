# Personal Resources Library

Benvenuti nel mio repository di risorse e guide allo studio per professionisti IT. Questo hub centralizzato raccoglie percorsi strutturati, documentazione tecnica e best practice su diverse aree di specializzazione, dall'ingegneria del software alla gestione di infrastrutture critiche.

## 📚 Struttura del Repository

Le risorse sono organizzate in percorsi di studio ("Power User") progettati per portare le competenze da un livello base a una padronanza professionale.

### 💼 Business & Strategia
*   [**01. Modello Business SaaS**](./01-MODELLO-BUSINESS-SAAS/): Fondamenti, metriche (LTV, CAC, Churn), architettura tecnica e strategie di monetizzazione per prodotti SaaS.

### 🖥️ Sistemi & Infrastruttura
*   [**02. Linux Power User**](./02-LINUX-POWERUSER/): Amministrazione avanzata, networking, sicurezza, kernel e performance optimization.
*   [**03. Windows Power User**](./03-WINDOWS-POWERUSER/): Active Directory, PowerShell, Group Policy e gestione moderna degli endpoint.
*   [**10. Migrazione VMware -> Proxmox**](./10-MIGRAZIONE-VMWARE-PROXMOX/): Guide pratiche per la migrazione di carichi di lavoro tra hypervisor.

### 💻 Programmazione & Sviluppo
*   [**04. Programmazione Python**](./04-PROGRAMMAZIONE-PYTHON/): Dalla sintassi base all'asincronia, design patterns e packaging.
*   [**05. Sviluppo Web**](./05-SVILUPPO-WEB/): Frontend (React, Vue, Svelte) e Backend (Node.js, API Design).
*   [**11. Godot Engine**](./11-GODOT-ENGINE/): Risorse per lo sviluppo di giochi e applicazioni interattive.
*   [**12. Software Engineering Extra**](./12-SOFTWARE-ENGINEERING-EXTRA/): Approfondimenti su architettura e metodologie di sviluppo.
*   [**16. Fortran**](./16-FORTRAN/): Programmazione scientifica, numerics, HPC e modern Fortran per calcolo ad alte prestazioni.

### ⚙️ DevOps & Automazione
*   [**06. Gestione Piattaforme**](./06-GESTIONE-PIATTAFORME/): Orchestrazione e gestione di ecosistemi complessi.
*   [**07. GitHub & GitActions**](./07-GITHUB-E-GITACTIONS/): CI/CD, workflow automation e gestione professionale del codice.
*   [**09. Automazioni Flussi di Lavoro**](./09-AUTOMAZIONI-FLUSSI-DI-LAVORO/): Scripting e strumenti per l'ottimizzazione della produttività.

### 🛡️ Operations & Sicurezza
*   [**08. Manutenzione IT**](./08-MANUTENZIONE-IT/): Checklist e procedure per la stabilità dei sistemi.
*   [**15. Security**](./15-SECURITY/): Hardening, analisi delle vulnerabilità e best practice di sicurezza difensiva.

### 📊 Data & Finanza
*   [**13. Trading**](./13-TRADING/): Algoritmi, analisi tecnica e strategie quantitative.
*   [**14. Data Engineering & Scienza dei Dati**](./14-DATA-ENGINEERING-E-SCIENZA-DEI-DATI/): Pipeline di dati, analisi statistica e modellazione.

---

## 🚀 Come utilizzare queste risorse

Ogni cartella principale contiene un file `00-guida-allo-studio.md` che funge da indice e piano d'azione per il percorso specifico. Si consiglia di iniziare dalla lettura di tale file per comprendere i prerequisiti e gli obiettivi di apprendimento.

## 🛠️ Manutenzione

Questo repository è in costante aggiornamento. Le guide riflettono l'evoluzione delle tecnologie e le esperienze maturate sul campo.
